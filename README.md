# Dada Ko Garage 🚲

A mobile-first static website for Dada Ko Garage, designed for GitHub Pages.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- No framework
- No unnecessary external libraries

## GitHub Pages
Live URL: https://katwalanim6-maker.github.io/Dadakogarage-/

## Before launch
Replace the confirmed business details in `script.js`:
- Phone
- WhatsApp
- Google Maps
- TikTok

Then replace gallery placeholders in `index.html` with the garage's real photos and add the verified business story, hours, address, services, prices and customer reviews.

No prices, testimonials, address or business claims are invented in the current version.
